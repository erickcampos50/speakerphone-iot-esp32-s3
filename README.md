# ESP32-S3 Audio — speakerphone experimental

Firmware Arduino C++ para a Waveshare ESP32-S3-AUDIO-Board. O estado real,
versões, testes pendentes e instruções de compilação estão em
[`docs/00-estado-atual.md`](docs/00-estado-atual.md).

**A última versão gravada está em `lab/speakerphone-ui/firmware` e ainda precisa
de teste após o upload.** AEC e redução de ruído não estão ativos; WiFi/web e
gravação são etapas posteriores. O DAC está configurado em 100%: inicie testes
com o volume do computador baixo.
